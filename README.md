# ⚡ Energy Meter Monitoring Web App

A full-stack web application built with **Node.js** (Express) and **React** to monitor energy meter consumption in real time. Designed for utilities and energy management systems, this app provides a streamlined interface to track and analyze consumption data from smart meters.

## 🚀 Features

- 📊 Real-time monitoring of energy meter consumption
- 🔍 Search and filter by meter ID, location, or status
- 📈 Data visualization with usage charts
- 🧩 Backend API with Node.js (Express)
- 🌐 Frontend UI with React
- 🔒 User authentication and access control (optional)
- 🧪 Unit and integration tests

## 🛠️ Tech Stack

| Layer      | Tech                        |
|------------|-----------------------------|
| Frontend   | React, Vite, Tailwind CSS   |
| Backend    | Node.js, Express, Sequelize |
| Database   | PostgreSQL or SQLite        |
| Others     | Docker, Jest, Supertest     |
